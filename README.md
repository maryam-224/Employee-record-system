# Employee Record System (C++)

An advanced C++ Object-Oriented Programming (OOP) project showcasing employee record creation, static class members, object cloning behavior (deep copy vs shallow copy pointer semantics), and dynamic memory management.

## 📌 Features & OOP Concepts

- **Static Attributes & Methods:** Uses `static const` variables for company name and keeps track of global `employee_count` across all instances.
- **Constructor Initializer List:** Efficient variable initialization upon object creation.
- **Copy Constructor:** Handles duplicate record creation while updating total employee metrics.
- **Dynamic Memory Allocation:** Demonstrates dynamic object instantiation using `new` and memory deallocation via `delete`.
- **Method Optimization:** Incorporates `this` pointer for attribute assignment and `const` member functions for read-only displays.
- **Pass-by-Value & Return Dynamics:** Demonstrates how objects interact when passed to or returned from non-member functions.

## 🛠️ Project Structure

- `main.cpp`: Complete application logic containing the `Employee` class definition, member functions, static initialization, and demonstration driver code.

## 💻 Tech Stack

- **Language:** C++
- **Paradigm:** Object-Oriented Programming (OOP)
- **Compiler:** GCC / Clang / MSVC (C++11 or higher)
